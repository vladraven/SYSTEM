1. PURPOSE

MacroRisk is a transparent, auditable and deterministic macroeconomic risk-monitoring system for Canada.

The system does not predict recessions, market crashes or investment outcomes. It calculates model-derived risk scores from explicitly defined official observations, deterministic transformations, normalization rules and configuration versions.

The system must never claim knowledge that the source data cannot support.

2. CANONICAL TECHNOLOGY MODEL

Mandatory:
- PHP 8.3+.
- Pure native PHP only.
- No Composer.
- No vendor/ directory.
- No Packagist dependencies.
- No frameworks.
- No third-party libraries.
- Native spl_autoload_register() PSR-4-compatible autoloader.
- Native ext-curl for official HTTP APIs.
- Native ext-json for storage and transport.
- Native ext-bcmath for all model arithmetic.
- Native PHP server-rendered PHP views.
- JSON files are the only persistent application datastore.
- Atomic file replacement and file locking are mandatory for writes.

Explicitly removed:
- MySQL and all other databases.
- PDO.
- ORM/DBAL.
- SQL migrations.
- Phinx.
- Doctrine.
- Symfony Console.
- Twig, Blade, Plates and other template engines.
- Runtime LLM decision engines.
- Third-party API wrappers.

The previous database/PDO/native-migrator architecture is superseded by this specification.

Every JSON file has a documented schema and schema_version.

Raw source responses are retained before transformation whenever practical. Normalized series preserve source identity, retrieval timestamp, release timestamp where available, reference period, raw value, status flags and source hash.

JSON writes:
1. write a temporary file in the same directory;
2. JSON encode with stable formatting;
3. flush and close;
4. atomically rename over the target;
5. use flock() for concurrent writers.

5. AUTOLOADING

The only autoloader is native spl_autoload_register(). Namespace root is MacroRisk\\ and maps to src/.

Example:

spl_autoload_register(static function (string $class): void {
    $prefix = 'MacroRisk\\';

    if (!str_starts_with($class, $prefix)) {
        return;
    }

    $relative = substr($class, strlen($prefix));
    $file = __DIR__ . '/src/' . str_replace('\\', '/', $relative) . '.php';

    if (is_file($file)) {
        require $file;
    }
});

6. DATA SOURCE POLICY

Production data must originate from official first-party sources:

1. Statistics Canada Web Data Service (WDS).
2. Bank of Canada Valet API.
3. Government of Canada Open Government Portal / CKAN API.

CMHC and CREA are not production-default sources where an official Statistics Canada or Government of Canada equivalent exists.

Third-party wrappers, scraped websites and unofficial API clients are prohibited.

The exact source contracts and native PHP request implementations are frozen in DATA_SOURCES.md.

7. SCIENTIFIC LAYERS

Every value must be classified as:
- Observation.
- Transformation.
- Model Output.
- Interpretation.
- Hypothesis.

Model output must never be presented as observed fact.

8. SCIENTIFIC INTEGRITY

Production text is blocked for unsupported certainty or causality.

Banned phrases include:
- will enter recession
- proves that
- model proves
- guarantees
- predicts with confidence
- recession is certain
- statistically confirms when N < 10
- caused by when causal identification is not established
- demographic collapse
- inevitable bankruptcy
- AI will fully replace
- immigration solves aging
- kondratiev
- juglar
- elliott wave
- market cycle predicts

9. DECIMAL POLICY

All model arithmetic uses BCMath strings.

No float is permitted in Domain or Risk calculation layers.

Internal scale: 8 decimal places.
Model/storage scale: 4 decimal places where specified.

Any float conversion in calculation code is a defect.

10. RISK SCORE INVARIANTS

Configured original weights must sum exactly to 100.0000.

Production calculation requires:
- coverage_ratio >= 60.0000;
- at least 3 eligible indicators;
- every required indicator eligible;
- source/license validation permits production;
- no blocking validation status.

Coverage is based on eligible original weights and is independent of frequency discounts.

Effective weights are calculated only after coverage validation, then frequency discounts are applied and the result is renormalized to 100.0000.

Rounding uses Round Half Away From Zero.

Rounding reconciliation priority:
1. largest original weight;
2. largest discounted weight;
3. smallest indicator_key using ASCII byte-wise ordering.

11. NORMALIZATION

Supported methods:
- threshold_linear
- distance_from_target_is_riskier
- outside_band_is_riskier

threshold_linear, higher_is_riskier:
x <= low => 0
x >= high => 100
otherwise ((x-low)/(high-low))*100

threshold_linear, lower_is_riskier:
x >= low => 0
x <= high => 100
otherwise ((low-x)/(low-high))*100

distance_from_target_is_riskier:
min(100, abs(x-target)/max_deviation*100)

outside_band_is_riskier requires:
outside_min < safe_min < safe_max < outside_max

Inside safe band = 0.
At or beyond outside boundary = 100.
Between boundaries = linear interpolation.

12. CALCULATION STATUS

Exactly:
- ok
- insufficient_data
- low_coverage
- required_indicator_missing
- missing_no_historical_data

For every non-ok calculation:
- risk_score = null;
- risk_band = null;
- the reason is deterministic and persisted.

13. RISK BANDS

Exactly:
- very_low
- low
- moderate
- high
- severe

Thresholds are configuration, not engine constants.

14. REPRODUCIBILITY

Every calculation preserves:
- model_version;
- configuration version/hash;
- source series identifiers;
- vintage date;
- selected observations;
- validation statuses;
- effective weights;
- normalized scores;
- contributions;
- calculation status;
- canonical calculation hash.

Identical persisted inputs and configuration must produce identical result and hash.

15. INGESTION

Pipeline:

Source request
-> raw response
-> source validation
-> parsed observations
-> normalized series
-> snapshot
-> calculation

Transport failure must never become a zero, fabricated value or silent missing observation.

16. NO SYNTHETIC DATA

Synthetic/generated economic observations are forbidden in production storage and production calculations.

Test fixtures live only under tests/fixtures/.

17. SECURITY

- No credentials in source control.
- Escape all external text before PHP-view output.
- Validate TLS certificates.
- Mandatory HTTP timeouts.
- Maximum response sizes.
- Validate external JSON before use.
- Do not blindly follow redirects to arbitrary hosts.

Legacy behavior is not authoritative. Existing behavior is retained only when it agrees with this specification.
