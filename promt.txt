1. Вводная инструкция агенту

Ты автономный senior PHP architect и implementation agent.

Твоя задача — реализовать полностью автономную, независимую систему макроэкономического мониторинга рисков Канады на чистом PHP 8.3+ с полным учётом циклических, структурно-демографических, фискальных и долговых факторов.

Если в рабочем окружении обнаружены сторонние пакеты, фреймворки, папка vendor или старый код с похожей бизнес-логикой, они не считаются источником истины. Реализация должна следовать только этой спецификации.

Native PHP float для расчётов весов, нормализации, risk scores или contribution values.

Обязательно к использованию:

2. Architecture Principles

Система должна проектироваться не как «умный прогнозатор», а как прозрачный, аудируемый и детерминированный механизм оценки макроэкономических рисков на основе явно заданных данных, правил, конфигураций, версий и ограничений.

Система оценивает макроэкономику через призму ликвидности, долга и демографии, полностью исключая эвристические «волновые теории» (циклы Кондратьева, Жюгляра и т.д.).

Приоритеты системы:

Correctness over feature count.

Transparency over automation.

Deterministic behavior over heuristics.

Auditability over convenience.

Modularity over monolithic implementations.

Explicit failures over silent recovery.

Explainability at every layer.

Обязательный архитектурный принцип:

Every production decision must be reproducible.

3. Non-Goals

Система не предназначена для того, чтобы:

Предсказывать рецессии, обвалы рынков или гарантировать раннее обнаружение кризисов.

Превосходить профессиональные эконометрические модели.

Делать causal inference без явной методологической поддержки.

Восстанавливать или «угадывать» недоступные данные.

Использовать generative AI как production decision engine.

Использовать эвристические модели (волновые теории, технический анализ) для расчёта риска.

Автоматически принимать финансовые или инвестиционные решения.

Представлять model-derived estimates как наблюдаемые факты.

Использовать прямые CMHC или CREA источники как production default, если доступны StatCan/Open Government equivalents.

Обязательное правило:

The system must not pretend to know what the data cannot support.

5. Indicator Matrix (Required Implementation Scope)

Система обязана поддерживать загрузку, трансформацию и расчет для следующих категорий индикаторов:

5.1. Macro & Inflation (macro)

CPI YoY / Core CPI: Инфляционное давление (StatCan).

Labor Productivity: ВВП на отработанный час (StatCan Table 36-10-0206-01). Нормализация: lower_is_riskier.

Bank of Canada Commodity Price Index (BCPI): Ресурсная база (BoC Valet). Нормализация: lower_is_riskier.

Unemployment Rate: Стандартный slack рынка труда (StatCan).

5.2. Financial & Liquidity (financial)

Yield Curve Spread (10Y-2Y): Монетарная жесткость (BoC). Нормализация: outside_band_is_riskier или lower_is_riskier (инверсия).

Financial Conditions Index (FCI): Доступность кредита (BoC). Нормализация: higher_is_riskier.

Corporate High Yield Spread: Институциональный кредитный риск. Нормализация: higher_is_riskier.

Household Debt Service Ratio (DSR): Доля дохода на обслуживание долга (StatCan Table 38-10-0238-01). Нормализация: higher_is_riskier.

Household Debt to Disposable Income: Общий леверидж (StatCan Table 38-10-0235-01). Нормализация: higher_is_riskier.

Business Insolvencies: Корпоративные банкротства (OSB). Нормализация: higher_is_riskier.

5.3. Housing Imbalances (housing)

NHPI / RPPI: Индексы цен на жилье (StatCan).

Housing Starts to Population Growth Ratio: Композитный структурный индикатор. Нормализация: higher_is_riskier.

5.4. Demographics & Fiscal (demographics, fiscal)

Elderly Dependency Ratio (EDR): Доля 65+ (StatCan Table 17-10-0005-01).

Government Deficit to GDP: Фискальный импульс/риск. Нормализация: higher_is_riskier.

6. System Invariants & Mathematical Precision

6.1 Risk Score Invariants

0.0000 <= risk_score <= 100.0000.

При 0 доступных индикаторах Score не рассчитывается (INSUFFICIENT_DATA).

Поля risk_score, normalized_indicator_score, original_weight, effective_weight, contribution_value, coverage_ratio, frequency_discount хранятся строго как DECIMAL(10,4).

Raw и transformed значения хранятся строго как DECIMAL(24,8).

6.2 Coverage Invariants

Production score рассчитывается только если одновременно:

coverage_ratio >= 60.0000%.

Все required индикаторы доступны.

Доступно минимум 3 индикатора.

Ни один используемый индикатор не имеет license_status = requires_license или unverified.

Ни один индикатор не находится в блокирующем статусе валидации.

Формула покрытия:
coverage_ratio = (СУММА(original_weight_available) / СУММА(original_weight_configured)) * 100%

6.3 Weight & Calculation Invariants

Все веса >= 0. Сумма original_weight в конфигурации строго равна 100.0000%.

При отсутствии индикаторов сумма effective_weight доступных индикаторов ренормализуется к 100.0000%.

frequency_discount (0 < fd <= 1.0000) применяются исключительно к effective_weight после проверки покрытия (для квартальных и годовых показателей fd задается <= 0.7000).

BCMath / Decimal Precision: Все вычисления весов, скоров и вкладов выполняются через bcmath. Нативный float в Risk Engine запрещён.

10. Risk Engine Mathematical Model

10.1 Transformation Rules (Composite Indicators)

Для составных индикаторов трансформация выполняется до нормализации.
Пример (housing_starts_to_population):
v_raw = Delta_Population_t / Housing_Starts_t

10.2 Threshold Linear Normalization (threshold_linear)

higher_is_riskier:

v <= low_risk_threshold => score = 0.0000

v >= high_risk_threshold => score = 100.0000

Линейная интерполяция внутри.

lower_is_riskier:

v >= low_risk_threshold => score = 0.0000

v <= high_risk_threshold => score = 100.0000

distance_from_target_is_riskier:

score = min(100.0000, (|v - target_value| / max_deviation) * 100)

outside_band_is_riskier:

Если safe_min <= v <= safe_max => score = 0.0000. За пределами полосы скалируется от 0 до 100 по границам low_risk_threshold / high_risk_threshold.

10.3 Weight Adjustment & Discounting

Базовая ренормализация доступных исходных весов:
w_i_base = (w_i_orig / СУММА(w_j_orig по всем доступным)) * 100

Применение frequency_discount (d_i):
w_i_disc = w_i_base * d_i

Итоговый effective_weight:
w_i_eff = (w_i_disc / СУММА(w_j_disc по всем доступным)) * 100

Вклад индикатора (contribution_value):
c_i = (s_i * w_i_eff) / 100

Итоговый risk_score:
risk_score = СУММА(c_i по всем доступным)

11. Appendix A: Worked Example (Test Fixture Subset)

(Демонстрационный расчёт сабсета индикаторов, покрывающих разные категории)

Конфигурация (Сумма 100%)

Household DSR (Quarterly): w_orig = 20.0000%, required = true, fd = 0.7000.

Housing Starts / Pop (Quarterly): w_orig = 20.0000%, required = false, fd = 0.7000.

Yield Spread (Monthly): w_orig = 20.0000%, required = false, fd = 1.0000.

Labor Productivity (Quarterly): w_orig = 20.0000%, required = false, fd = 0.7000.

Business Insolvencies (Monthly): w_orig = 20.0000%, required = false, fd = 1.0000.

Данные и нормализация

DSR: val = 15.2000, low = 13.0000, high = 15.5000 (higher_is_riskier) => s_1 = 88.0000.

Housing/Pop Ratio: val = 4.5000 (4.5 чел на 1 старт), low = 2.0000, high = 5.0000 (higher_is_riskier) => s_2 = 83.3333.

Yield Spread: val = -0.5000, low = 1.0000, high = -1.0000 (lower_is_riskier) => s_3 = 75.0000.

Productivity: val = 104.0000, low = 108.0000, high = 100.0000 (lower_is_riskier) => s_4 = 50.0000.

Insolvencies (YoY %): val = 25.0000, low = 5.0000, high = 35.0000 (higher_is_riskier) => s_5 = 66.6667.

Расчёт

Coverage Ratio: 100.0000% (>= 60% => PASS).

Дисконтированные веса (w_disc = w_orig * fd):

DSR: 20.0000 * 0.7000 = 14.0000

Housing: 20.0000 * 0.7000 = 14.0000

Yield Spread: 20.0000 * 1.0000 = 20.0000

Productivity: 20.0000 * 0.7000 = 14.0000

Insolvencies: 20.0000 * 1.0000 = 20.0000

Сумма w_disc = 82.0000

Итоговые Effective Weights (w_eff):

DSR: 14.0000 / 82.0000 * 100 = 17.0732%

Housing: 14.0000 / 82.0000 * 100 = 17.0732%

Yield Spread: 20.0000 / 82.0000 * 100 = 24.3902%

Productivity: 14.0000 / 82.0000 * 100 = 17.0732%

Insolvencies: 20.0000 / 82.0000 * 100 = 24.3902%

Сумма w_eff = 100.0000%

Вклады (c_i = s_i * w_i_eff / 100):

DSR: 88.0000 * 0.170732 = 15.0244

Housing: 83.3333 * 0.170732 = 14.2277

Yield Spread: 75.0000 * 0.243902 = 18.2927

Productivity: 50.0000 * 0.170732 = 8.5366

Insolvencies: 66.6667 * 0.243902 = 16.2601

Итоговый Risk Score:
risk_score = 15.0244 + 14.2277 + 18.2927 + 8.5366 + 16.2601 = 72.3415 (Band: high)
